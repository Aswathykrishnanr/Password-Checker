# Password Strength Checker

A small, single-page password strength checker built with HTML, CSS and
JavaScript. It runs entirely in the browser.

## Features

- Password box with a show/hide toggle
- Live strength bar: red (weak), orange (medium), green (strong)
- Checklist: 12+ characters, uppercase, lowercase, number and symbol

## Run it

1. Download `index.html`.
2. Open it in any web browser.
3. Type a test password and watch the bar and checklist update.

## Privacy

Nothing is saved or sent anywhere. Use made-up test passwords only.
This is a simple rule-based checker, not a real security test.
